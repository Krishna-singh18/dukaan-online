# DukaanOnline – Digital Kirana Store Website

A modern, fast, mobile-first e-commerce website template designed for local Kirana and neighborhood grocery stores in India with direct WhatsApp order integration.

## Key Features

- **Store Configuration System**: Easily customize store name, address, contact numbers, delivery charges, and banners from a single config file (`storeConfig.js`).
- **Direct WhatsApp Ordering**: Customer cart, address, and delivery preferences are formatted and sent directly to the store owner's WhatsApp.
- **Mobile-First Experience**: Designed specifically for smartphone shopping with touch navigation, bottom navigation bar, and clean UI.
- **No Backend Required**: Runs client-side with LocalStorage cart persistence, ready for future API integration.

## Tech Stack

- **React.js (Vite)**
- **Tailwind CSS**
- **Lucide React**
- **LocalStorage API**

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
